# Иконки Nyx VPN

Положите сюда PNG-иконки размером **128×128 px**.

## Список используемых иконок

| Файл | Где используется | Рекомендуемый размер |
|---|---|---|
| `logo.png` | Логотип в шапке | 128×128 |
| `crown.png` | Иконка статуса премиум | 128×128 |
| `gift.png` | Пробный период / главная карточка | 128×128 |
| `card.png` | Баланс в статус-ряду | 128×128 |
| `referral.png` | Рефералы | 128×128 |
| `home.png` | Нижнее меню "Главная" | 128×128 |
| `subscribe.png` | Нижнее меню "Подписка" | 128×128 |
| `wallet.png` | Нижнее меню "Баланс" | 128×128 |
| `support.png` | Нижнее меню "Поддержка" | 128×128 |

## Формат

- PNG с прозрачным фоном (PNG-24 с alpha)
- Монохромные иконки (чёрный или белый цвет)
- CSS-фильтр автоматически перекрасит их в акцентный жёлтый / тёмно-золотой

## Если иконки отсутствуют

WebApp автоматически покажет fallback-эмодзи.
